# Proposal Price Table Calculator

A lightweight, browser-based calculator for preparing project quotation man-day allocations and payment milestones.

## Usage
Open `index.html` in any modern browser, or enable GitHub Pages for this repository.

## Features
- Project target amount, rate/category inputs, and total estimated man-days
- Clone staff category rows with `+`
- Percentage-based milestone allocation with manual adjustments
- Milestone-specific staff category applicability
- Read-only milestone verification table
- Built-in allocation and price status checks

**Split by System:** Developing (currently disabled).

## Deployment
In GitHub repository settings, open Pages, choose **Deploy from a branch**, then select **main** and **/(root)**.

No backend or build step is needed.
